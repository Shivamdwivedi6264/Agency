# Excel Sales Analysis Dashboard

## Project Overview
This project analyzes sales performance and profitability using Microsoft Excel. It features an interactive executive dashboard that summarizes key business metrics and presents sales insights through charts, KPI cards, and slicers.

## Tools & Techniques
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Excel Formulas
- Data Visualization
- KPI Reporting

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Gross Profit
- Gross Profit Margin (%)
- Total Units Sold
- Total Orders
- Cost of Goods Sold (COGS)

## Dashboard Analysis
- **Monthly Revenue & Profit:** Tracks monthly revenue and gross profit trends.
- **Top 5 Countries by Revenue:** Compares revenue performance across selected countries.
- **Revenue Share by Channel:** Analyzes revenue contribution from different sales channels.
- **Region-wise Comparison:** Compares sales performance across European regions.
- **Country-wise Map Chart:** Visualizes revenue distribution geographically.

## Interactive Features
- Product Category slicer
- Country slicer
- Quarter slicer
- Pivot Analysis and Data navigation buttons
